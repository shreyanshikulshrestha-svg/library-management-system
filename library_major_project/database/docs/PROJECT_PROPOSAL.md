# Project Proposal (submit before starting development)

**Project title:** Library Management System Using PHP and MySQL

**Subject:** Web Technologies – Major Project 1: Design and Develop a Database-Driven Web Application

**Brief description:**
A responsive web application that helps a college library manage its daily work. Staff can add and maintain books, register students, issue books to students, record returns, and view all issue records. The system updates book stock automatically, restricts each student to 3 books at a time, and calculates a fine of Rs. 5 per day for late returns. Search is available for books, students and issue records.

**Technologies:** HTML5, CSS3, JavaScript, PHP, MySQL, VS Code, XAMPP
